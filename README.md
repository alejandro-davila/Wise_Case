# PartnerBank quarterly review (Wise Platform case study)

A short Streamlit app answering the four case-study questions. All PartnerBank figures are illustrative and come from a mock dataset.

**Summary**
1. **QBR:** usage is up 13% and reliable, but 42% of customers' money goes to Wise directly, 35% because of app limits that can be fixed.
2. **Convenience fee:** 0.3% with a £1 minimum and a £15 cap, tested against a control group first.
3. **Multi-currency accounts:** 17% of PartnerBank's customers on Wise already use one.
4. **Internal case:** judge it on new revenue Wise would not earn anyway; fund a one-partner pilot first.

Run locally:

    pip install -r requirements.txt
    streamlit run app.py
